# AI Chatbot 手機即時預覽

- 狀態：Demo 提案；正式觀眾端介面待確認。
- 目的：讓內容編輯者在 Settings 調整文案時，立即看見手機版開場與無結果狀態，減少在設定頁與 Playground 之間反覆切換。

## 本機 Demo 範圍

- 左側助手名稱、開場文案、推薦問題、無結果引導與防劇透設定，反映在右側手機預覽。
- 可切換「開場／無結果」，以及「設定草稿／已發布版本」；尚未發布時停用已發布選項。
- 點選推薦問題會前往 Playground，並將該問題放入輸入框，供編輯者測試。
- 手機版面使用現有 shadcn/ui 控制項及中性視覺，不代表正式品牌或 C 端設計。
- 資料仍保存在目前瀏覽器的 localStorage；「Publish Demo」只建立本機設定快照。

## 待確認

- 正式手機介面的視覺規格、語系與可用的畫面寬度。
- 防劇透在觀眾端的具體呈現方式，以及搜尋結果卡片的規格。
- 正式版是否需要裝置尺寸切換、分享預覽連結與跨人員審核。
